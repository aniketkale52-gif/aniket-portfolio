# Aniket Kale · Portfolio

Personal portfolio website. Plain HTML/CSS/JS, no framework, no build step.

## Run it locally
Needs Node.js 18 or newer (nodejs.org, LTS). No `npm install` required.

    npm run dev

Then open http://localhost:3000. Saving any file reloads the page automatically.

## Deploy
- Pushing to `main` updates the live site on Vercel.
- Pushing any other branch (for example `staging`) creates a preview URL.
